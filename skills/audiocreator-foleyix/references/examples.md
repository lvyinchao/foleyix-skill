# 代表性输入与可提交提示词

只在需要结构示例时阅读。以下为人工编写示例，不是已生成或已审听的声音，也不是强制模板。复制结构时替换为本次需求，不能把示例台词／时长／背景自动带入。模式是任务标签，声音内容在文本里。

## 1. 保留未加引号的台词

用户：`优化配音提示词：温柔地读下面这句，不要音乐。欢迎回家，今天也辛苦了。`

建议（narration）：

```text
温柔地朗读：“欢迎回家，今天也辛苦了。”
不要音乐。
```

核对：稿件与“不要音乐”逐字保留；不增加女声、年龄、背景或时长。

## 2. 原创角色预览字段

用户：`设计一位原创女船长的音色，低而沙哑、果断，给我一句短预览台词。`

声音描述：`原创成年女船长，女声中低音，略带沙哑但口齿清晰；语气果断，句尾干脆。`

样例台词：`收起船帆，所有人跟我走。`

核对：明确授权写短台词；这是角色设计两个字段，不是另一个 CLI 模式。网站会制作单人干声预览，不能声称已创建角色或已绑定参考。

## 3. 已绑定双人对白

用户：`工作台已选好参考，林是@voice1，周是@voice2。雨夜重逢，林轻声说“你还是来了。”，周停顿后说“我答应过你。”雨在远处，不要音乐。`

建议（dialogue）：

```text
雨夜重逢。远处雨声持续，保持在对白之后。
林（@voice1）轻声说：“你还是来了。”
周（@voice2）停顿后说：“我答应过你。”
不要音乐。
```

核对：两个引用与顺序不变，两句台词不变。若没有实际绑定，则不能照用这个版本。

## 4. 授权创作播客开场

用户：`写一个男女双主播的中文旅行播客开场，主题是放慢脚步，有自然接话，不要配乐或环境声。`

建议（podcast）：

```text
中文双主播旅行播客开场。阿远是温和的男声，小夏是清晰明亮的女声，两人的声音保持区分，自然轮流接话。
阿远轻松地说：“旅行时，你会不会总想把行程塞满？”
小夏带着笑意回答：“会，可我记得最清楚的，反而是在小店门口发呆的下午。”
阿远接着说：“这期我们聊聊，怎样把旅行的脚步放慢一点。”
不要配乐或环境声。
```

核对：用户允许写开场，所以可以新写台词和必要的人物身份；不添加音乐、城市事实或声效。

## 5. 纯音效

用户：`我要空旷仓库里远处金属门关闭的音效，一次撞击，回响消失，不要人声或音乐。`

建议（sfx）：

```text
空旷仓库里，远处一扇金属门关闭，产生一次短促的金属撞击声。撞击后回响逐渐衰减，最后归于安静。
不要人声或音乐。
```

核对：只生成这个事件；不编仓库里的对白、脚步或配乐。

## 6. 持续环境声

用户：`30秒的森林雨声，雨点落在树叶上，远处有轻微风声，不要动物、人声或音乐。`

建议（ambience）：

```text
约30秒的森林雨声环境。雨点持续落在树叶上，形成清楚但柔和的沙沙声；远处轻微风声在背景持续，雨声是主要声音。整体稳定自然。
不要动物、人声或音乐。
```

核对：不加鸟鸣或雷声，不把30秒称为保证；若任务是严格优化已有提示词，应原样保留“30秒”要求的原文而非改写。

用户：`为读书视频设计45秒Lo-fi纯音乐提示词，温暖电钢琴、轻鼓，舒缓，自然结束，不要歌词和任何人声。`

建议（free）：

```text

核对：不用 `music` 模式；不同时要求无缝循环和自然终止。优化已有文本时禁止项需保留原文，本例是新创作。

## 8. 修复反馈，保留有效部分

用户：`这是原提示词：小禾平静地说：“明天见。”背景雨声持续。不要音乐。实际雨声太响盖住了人声，帮我修提示词。`

背景雨声持续，音量轻且保持在远处。人声清楚地位于前景，雨声不遮盖这句对白。

```

核对：只围绕背景遮蔽修改，台词、情绪、雨声与禁止项保留；不声称修复后声音已验证。

## 边界自检请求

- `把这段3500字稿件逐字朗读，不要删字`：不能只返回前3000字或摘要，需按句分段并计算包含共有指令的每段完整长度。
- `四位角色都必须绑定自己的参考音`：每次最多三条参考，需分段／调整方案；四位文字描述角色本身不受三条参考数限制。
- `给日语原句配音，只要提示词`：原句保持日语，不因为官方列出中英文就翻译或拒绝，不能承诺同等效果。
- `不要人声，同时必须念出这句话`：指出直接冲突，获取选择；不默默删除对白或禁止项。
- `我只有样例链接，帮我完全复现同一音色`：没有听到就不编音色细节，实际参考未绑定就不使用假编号，不保证完全复现。
- `优化：不要音乐，台词是“到账 3,000 元。”`：保留完整禁止项、标点、数字与台词，不把文字3000误判为输入长度或加广告收尾。
